# 📚 Documentação do Agente Genérico de EDA

Bem-vindo à documentação completa do Agente Genérico de Análise Exploratória de Dados (EDA).

## 📖 Índice da Documentação

### 1. [Fluxograma](./fluxograma.md)
Fluxos de funcionamento do agente, incluindo:
- Fluxo principal de execução
- Fluxos de cada ferramenta
- Fluxo de geração de gráficos
- Fluxo de memória de conclusões
- Diagramas Mermaid interativos

**Recomendado para**: Entender como o agente funciona internamente

### 2. [Ferramentas](./ferramentas.md)
Documentação detalhada de todas as 6 ferramentas:
- `load_csv`: Carregamento de datasets
- `check_dataset_loaded`: Verificação de dataset
- `get_dataset_info`: Informações do dataset
- `execute_analysis`: Execução de código Python
- `save_conclusion`: Salvamento de conclusões
- `get_conclusions`: Recuperação de conclusões

**Recomendado para**: Aprender a usar cada ferramenta

### 3. [Arquitetura](./arquitetura.md)
Arquitetura técnica do sistema:
- Componentes principais

- Decisões de design
- Otimizações e melhorias futuras

**Recomendado para**: Desenvolvedores que querem entender ou modificar o código
